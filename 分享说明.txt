pdfedit — PDF 文本编辑器（仿WPS编辑内容）
============================================

【怎么用】
1. 解压整个文件夹（保持 pdfedit.exe 与 _internal 文件夹在一起）
2. 双击 pdfedit.exe —— 无需安装 Python 或任何依赖
3. Ctrl+O 打开 PDF → 点击文字原位编辑（Enter 确认/Esc 取消）
   按住文字拖动可移动位置（带对齐参考线与吸附），Ctrl+Z/Y 撤销重做
4. Ctrl+S 保存：采用标准增量更新写回，原文件字节不动，其他阅读器均可打开

【系统要求】
- Windows 10/11 64 位
- 中文编辑依赖系统自带字体（简体中文 Windows 均已内置）

【首次运行提示】
- SmartScreen 可能提示"已保护你的电脑"：点"更多信息"→"仍要运行"
  （未签名 exe 的正常现象；本程序仅本地读写你指定的 PDF 文件，无联网功能）
- 个别杀毒软件可能误报（PyInstaller 打包的常见误报），可添加信任

【技术架构】
- 基于 PyMuPDF(MuPDF) 引擎 + PySide6(Qt) 界面
- 编辑模型：定位文字 → 背景采样 → redaction 真删除 → 新字体子集嵌入 → 增量写回
- 完整设计文档见 源码/README.md

【许可须知（重要）】
- 本程序动态链接 PyMuPDF（MuPDF 内核，AGPL-3.0 许可）与 PySide6（LGPL-3.0）
- 因此：自由分享、学习、个人/内部使用没有问题；本包已随附全部源码以满足 AGPL 要求
- 若要闭源商用分发，需向 Artifex 购买 MuPDF 商业授权，
  或将内核更换为 PDFium（Apache-2.0，即 WPS/Chrome 的 PDF 内核，无此限制）
- Windows 系统字体（宋体/黑体等）不可随包再分发，故未打包字体文件
